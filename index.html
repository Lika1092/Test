196. Из 25 учеников в классе 17 изучают английский язык, а 15 – французский. Сколько детей изучают оба языка?

Обозначим количество учеников, изучающих английский язык, как A=17, а количество учеников, изучающих французский язык, как B=15. Общее количество учеников в классе равно N=25. Пусть x – количество учеников, изучающих оба языка. Тогда количество учеников, изучающих только английский язык, будет A−x, а количество учеников, изучающих только французский язык, будет B−x. Согласно принципу включения-исключения, N = (A−x) + (B−x) + x. Подставим значения: 25 = (17−x) + (15−x) + x → 25 = 32 − x → x = 7. Таким образом, количество учеников, изучающих оба языка, равно 7.
